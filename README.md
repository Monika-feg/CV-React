## CV

Det hjär är ett CV gjort i React

## verktyg

Jag har använt mig av:
*React
*TypeScript
*Radix-ui/React-icons
*React-Router-Dom

## installera

1.  clona ner detta report:

```bach
   git clone git@github.com:Monika-feg/CV-React.git
```

Innan du startar projectet så gör du:

```bach
   npm install
```

Och för att starta:

```bach
   npm run dev
```
